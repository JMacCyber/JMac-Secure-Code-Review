JMac Secure Code Review

What It Does

It reads code, finds security mistakes, and tells you what it checked and what it did not.
1. You Point It At Code
  • What you staged --staged
  • One commit --commit
  • A branch or range --base
  • A whole repository --all
2. It Checks For
  • Passwords, keys and tokens left in files
  • User input passed to the shell or eval
  • CI settings that grant too much access
  • Risky cloud and container settings
  • Dependencies and licences to look at
Optional: an AI second opinion. Off until you turn it on, and it must quote real lines or its finding is thrown out.
3. It Reports
  • What ran, and what did not, first
  • Each finding: severity, file, line, fix
  • Text, JSON, SARIF or one offline HTML page
0Nothing at or above the bar 1Found something 2Could not run 3Part of it did not finish
