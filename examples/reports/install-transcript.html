Installing JSCR

A clean virtual environment, start to first policy. Nothing else was installed.
$ git clone https://github.com/JMacCyber/JMac-Secure-Code-Review jscr
$ pip install ./jscr
$ pip list --format=freeze
jscr==0.1.0
pip==21.2.4
setuptools==58.0.4

$ jscr init
wrote /home/dev/sample/.jscr.json
Egress is closed and the provider is 'null'. JSCR will run its deterministic checks and nothing will leave this machine until you set provider.name, provider.endpoint, egress.enabled and egress.allow_hosts yourself.

$ jscr policy
Policy for /home/dev/sample
------------------------------------------------------------------------
  allow  fs.read            repository reads are the purpose of the tool
  deny   net.connect        egress.enabled is false
  allow  provider.use       provider 'null' is the configured provider
  deny   exec.run           scanners.semgrep is false
  deny   tool.call          tools.allow is empty
  deny   persist.write      persistence.mode is metadata_only; 'review output' is not metadata
  deny   telemetry.send     telemetry.enabled is false
  deny   update.check       update.check is false; JSCR does not update itself
Three packages in the environment: jscr, and pip and setuptools, which the environment ships with. JSCR pulls in nothing of its own.
